The program searches for words in one or two dictionaries using one of the search options. English dictionary contains 393,167 words, Russian 2,415,401 words. In addition one can view dictionary statistics, frequency of word length (descend), two nearby characters distribution, letters frequency.

Program homepage [https://slovesnov.rf.gd?words](https://slovesnov.rf.gd?words)
